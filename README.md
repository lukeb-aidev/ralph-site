# Ralph website

Public product information, support and privacy for Ralph, an iPhone app in development.

The website is published at https://lukeb-aidev.github.io/ralph-site/ using GitHub Pages from the root of `main`. It is separate from the private application repository.

## Maintain

Edit the static HTML pages and `assets/styles.css`. Keep links relative to each page so the site works under its GitHub Pages project path. No build, JavaScript runtime, analytics or form service is required.

Preview locally with `python3 -m http.server 8766` and open the printed local URL. Check Home, Support and Privacy at desktop and narrow phone widths before publishing. Verify all internal links and preserve the attribution headers.

The logo and mascot are Ralph artwork. App images are development captures, not release-qualification evidence. The website and application artwork are copyright 2026 Lukas Bower; this repository does not grant a licence to reuse the identity.

The contact option currently uses this repository’s public GitHub issues. A dedicated support email can be added after its ownership and operation have been confirmed. Do not publish an unverified mailbox.
